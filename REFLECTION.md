Overall Reflection

This lab helped me understand that CSS layout problems usually have a logical explanation. The Cascade determines which conflicting style rule wins, combined selectors allow elements to be targeted more precisely, positioning controls where elements appear, and the box model explains how elements occupy space.

The part I found most useful was seeing how position: relative and position: absolute work together. I also learned that small HTML syntax mistakes can affect how the browser interprets a page. For example, I forgot the opening < in an <h1> tag, which caused part of the tag to appear as text in the browser. Fixing this helped me become more careful when checking HTML syntax and debugging browser output.
